# One Letter for Your Day — Z

Entry for [One Letter for Your Day](https://make.fun/c/u-puan-one-letter-for-your-day-e54e9c36) on make.fun.

The program writes exactly one character to `/output/entry.txt`: the letter **Z** — for zombie, zero sleep, zonked. One letter, nothing else, no trailing newline.
